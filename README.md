Данная лабараторная работа расчитана на улучшение понимания Git и Python.

В папке [src](./src) лежит основой код моей программы. 

Мой калькулятор работает с выражениями, записанными в обратной польской нотации.
Обратная польская нотация (ОПН) - форма записи математических и логических выражений, в которой операнды расположены перед знаками операций.
(Выражение 2+3×4 в обратной польской нотации записывается так: 2, 3, 4, ×, +)
Он поддерживает базовые арифметические операции
(сложение(+), вычитание(-), умножение(*), деление(/), целочисленное деление(//), остаток от деления(%) и возведение в степень(**)),
обработку вещественных и целых чисел, скобки, унарные плюс($) и минус(~) а также выражения с учетом приоритетов операций.

Стоит отметить, что обратная польская нотация не предполагает ввод скобок, однако в моем калькуляторе они допустимы для визуального упрощения выражения.
(главное вводить их корректно, иначе можно получить предупреждение :) )

Описание модулей:
Основной класс Calculator реализует вычисления и находит ошибки, и при их наличии сообщает об этом. 
Ошибки выводятся с пояснением, поэтому пользователю понятно, что именно не так с введенным выражением.

Класс Tokenizer для разбора входных выражений на токены. Группа содержит в себе проверку строки при помощи регулярного выражения.
Так же проверяет сбалансированность скобок и возвращает соответствующую ошибку, если ввод был нарушен. 

В папке tests находятся тесты, которые помогают оценить работоспособность кода(мы проверяет корректрность работы не только для верно введенных выражений, 
но и для ошибочных, чтобы убедиться в том, что наша программа верно предупреждает пользователя о неверном вводе)

Для запуска у вас должен быть установлен Python (точно работает на 3.13). Нужно перейти в файл main и запустить программу.
Вас встретит небольшая инструкция. После чего можете вводить желаемое выражение
